# IRONLOG PUSH/PULL

Statyczna aplikacja treningowa HTML/CSS/JavaScript. Nie wymaga builda ani backendu.

## Publikacja przez GitHub Pages

1. Na GitHubie utwórz nowe repozytorium, np. `ironlog`.
2. Ustaw repozytorium jako Public (albo upewnij się, że Twój plan obsługuje Pages dla repozytorium prywatnego).
3. Wybierz **Add file → Upload files** i wgraj `index.html` z tego folderu.
4. Wejdź w **Settings → Pages**.
5. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
6. Wybierz gałąź `main` oraz folder `/(root)`, następnie kliknij **Save**.
7. Po zakończeniu publikacji GitHub pokaże adres aplikacji w sekcji Pages. Otwórz ten adres bezpośrednio w Safari/Chrome, nie w podglądzie pliku.
8. Na iPhonie w Safari wybierz **Udostępnij → Dodaj do ekranu początkowego**.

## Ważne

- Historia jest zapisywana w `localStorage` danej przeglądarki i domeny. Inna przeglądarka/urządzenie ma osobną historię.
- Eksportuj kopię JSON regularnie.
- Nie czyść danych witryny, jeśli chcesz zachować lokalną historię.
- To prototyp; przed intensywnym użyciem przetestuj zapis treningu, eksport i import.
